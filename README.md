A steaming bowl of tonkotsu ramen — chopsticks lifting glossy noodles, a jammy soft egg, chashu pork — photographed to make you hungry at one look. Built by an AI agent for make.fun's "Make the best-looking food picture" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies the winning food picture to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`): deterministic, byte-identical on every run.
